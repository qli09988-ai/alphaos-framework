00｜用户真正的问题，不是“蓝箭好不好”

当用户问“鲁信创投怎么样？好像跟蓝箭IPO相关”，这通常意味着：用户已经听到风声，但尚不知道这条信息是否足以形成交易决策。

能买吗？
什么时候买？
大概能涨多少？
是不是一定涨？
什么时候卖？
研究起点 “蓝箭IPO → 鲁信受益”只是一个叙事起点。要形成决策，必须继续追问：鲁信到底持有多少经济权益？价值已在账上反映多少？市场已经提前交易多少？下一次状态跃迁是什么？

01｜最终状态卡：先给答案，再展开推导

当前状态
🟡 重点观察；尚未出现高质量事件买点
核心事实
蓝箭IPO真实推进，最新公开审核状态仍为“已问询”；鲁信体系三只基金合计持有蓝箭0.89%，但公司曾明确提示穿透后对财务及经营成果影响较小。
价值主体
不是“单押蓝箭”，而是“IPO资产包 + 退出能力 + 创投平台溢价”；蓝箭更像高关注度催化剂。
当前预期
8月事件亢奋已经明显释放；但以2026H1归母净资产为基准，市场仍给予较高资产溢价。
最重要触发
蓝箭由“已问询”进入更高审核节点，或其他核心IPO项目出现实质状态跃迁，同时鲁信股价没有提前明显抢跑。
失效/降级
事件长期不推进；IPO资产包兑现明显变慢；股价上涨幅度远超可解释的NAV增量；或市场进入高风险退潮。

这张卡是 Decision Mode。下面保留完整的“研究决策轨迹”，让专业读者看到每一步为什么发生，而不是只看最终结论。

02｜研究方法：先给证据分层，避免“故事越聊越真”

本案例不把所有公开材料视为同等可信。每个结论按以下标签表达：

FACT2026H1 鲁信归母净资产为 45.5117亿元，归母净利润约 1.9577亿元；投资收益约1.6128亿元，公允价值变动收益约1.5090亿元。来源：公司半年报 [S1]。

FACT截至2026H1，公司及参股基金/投资平台共有 27个拟IPO项目，其中13个已被交易所受理、14个处于辅导期；2026H1退出回笼资金3.71亿元。[S2]

FACT鲁信创投曾在异常波动公告中明确提示：三只参股基金合计持有蓝箭0.89%，股权穿透后对公司财务状况和经营成果影响较小。[S5]

因此，本案例不能把“0.89%”直接当成鲁信上市公司自身持股比例。 基金层持股比例、鲁信在基金中的经济权益、会计计量、锁定期、退出价格和收益分配都要继续穿透。

03｜Step 1：蓝箭到底给鲁信值多少钱？

3.1 先拆掉最容易误导的口号

FACT公司口径是“三只参股基金合计持有蓝箭0.89%”，不是“鲁信创投直接持有蓝箭0.89%”。[S5]

FACT蓝箭招股书披露，成都鲁信菁蓉贰期是其股东之一；招股书同时披露了该基金的合伙人结构。[S3]

3.2 工作穿透值：约0.43%，但不作为公司确认口径

CALCULATION公开市场存在一套对三只基金逐层穿透后的重构，得到鲁信对蓝箭的有效经济权益约 0.4334%。[S7]

MISSING这一数值不是鲁信公司直接披露的最终经济权益口径；基金份额变化、GP/LP间接权益、收益分配机制等均可能影响精确值。因此本文只把 ≈0.43% 当作“工作估算”，不用它制造精确目标价。

工作估算： 蓝箭估值 × 鲁信穿透经济权益 ≈ 对应蓝箭权益价值 若以 0.43% 为工作估算： 300亿元 × 0.43% ≈ 1.29亿元 500亿元 × 0.43% ≈ 2.15亿元 1000亿元 × 0.43% ≈ 4.30亿元 注意： “权益总价值” ≠ “新增NAV” 还要扣除/比较当前已经计入账面或公允价值的部分， 并考虑基金层收益分配、锁定、税费、退出价格等。

3.3 这一步改变了什么？

INFERENCE即使给予蓝箭很高的估值，单一蓝箭项目对鲁信整体价值的解释力也可能只是数亿元级；而鲁信本身是百亿元市值公司。因此“蓝箭IPO影子股”不能自动推出“鲁信有巨大未计价价值”。

INFERENCE研究问题必须从“蓝箭值多少钱”升级为：“整个IPO资产包有多大兑现潜力？蓝箭在其中到底是什么角色？”

04｜Step 2：真正的价值主体，从“蓝箭”升级为“IPO资产包”

FACT2026H1鲁信及相关基金/平台共有27个拟IPO项目，其中13个已受理、14个辅导；珞石机器人于2026年7月9日在港交所上市，思朗科技于7月7日获科创板受理。[S2]

FACT2026H1公司控股/参股基金及投资平台共59个，总认缴规模228.65亿元，到位资金162.35亿元；报告期退出回笼资金3.71亿元。[S2]

Thesis 发生第一次重构 初始叙事：鲁信 = 蓝箭IPO影子股。
重构后：鲁信 = 一篮子未上市/拟上市资产 + 退出能力；蓝箭 = 高关注度催化，而非全部价值主体。

4.1 为什么不能把所有IPO后的市值都当“新增价值”？

FACT创投公司的资产会通过长期股权投资、交易性金融资产、其他非流动金融资产等方式进入报表；鲁信2026H1本身已经确认了较大的投资收益和公允价值变动收益。[S1]

INFERENCEIPO更像“估值透明度 + 流动性 + 退出通道”的状态提升，而不是让一项资产从0突然变成全部市值。因此必须计算增量NAV，而不是“IPO后市值 × 持股比例”这么简单。

4.2 Reverse Expectation：市场已经为未来付了多少？

CALCULATION2026H1归母净资产45.5117亿元；以9月18日收盘15.35元和7.4436亿股总股本计算，市值约114.3亿元。对应约2.51倍PB，市场价格较账面归母净资产高约68.8亿元。

市场隐含溢价（仅作框架观察）： 市值 ≈ 15.35 × 7.4436亿股 ≈ 114.3亿元 H1归母净资产 ≈ 45.5亿元 差额 ≈ 68.8亿元 这个差额不能全部叫“蓝箭溢价”； 它同时包含：未上市资产成长、退出能力、未来投资能力、 平台属性、主题偏好以及情绪溢价。

INFERENCE所以真正的问题不是“蓝箭能贡献4亿元，所以鲁信被低估”，而是：整个资产包和未来退出能力，是否足以长期支撑市场已经给予的高于账面净资产的溢价。

事件越往右，确定性通常提高；但市场往往也会提前交易，所以“确定性最高”不等于“赔率最好”。

5.1 为什么鲁信不是 Single Event Bet？

INFERENCE蓝箭是最吸睛的事件，但鲁信同时拥有多个拟IPO项目，因此更准确的描述是 Portfolio of Catalysts。一个项目延迟不必然击穿整个Thesis；但如果多个项目的兑现速度一起变慢，资产包逻辑会明显降级。

5.2 事件状态的核心观察

AlphaOS不需要每天重写研报，而应监控“有没有项目发生离散状态跃迁”。对蓝箭而言，当前最重要的是：

C3 → C4 从“已问询”进入上市委/更高确定性审核节点。状态跃迁发生后，再重新计算NAV影响、市场反应和赔率。

6.1 第二次Thesis重构：从“消息真假”升级为“消息被交易多少”

INFERENCE蓝箭相关进展可以是真实利好，但如果资金已经提前把未来价值和情绪溢价交易进去，利好落地当天甚至可能接近阶段性卖点。

7.1 当前为什么仍是“重点观察”？

FACT蓝箭仍在C3已问询，没有新的公开C4状态跃迁。[S4]

CALCULATION价格已从8月事件高位明显回落，但仍交易在约2.51倍H1 PB附近。

INFERENCE因此当前是“预期降温了，但新证据还没来”的组合。比8月事件亢奋时更值得跟踪，但还不足以单靠价格回撤升级成高质量入场状态。

7.2 入场条件矩阵

A｜事件向前：蓝箭C3→C4，或其他核心IPO项目出现实质状态跃迁，或真实退出/NAV兑现增强。

B｜不能明显抢跑：若状态跃迁前股价已连续大涨、成交极度放大，则赔率可能已被提前吃掉。

C｜价值要撑得住：重新测算新增NAV，比较“资产价值变化”和“市值变化”，避免2亿元价值增量换来20亿元市值扩张。

D｜市场环境：高预期创投资产对风险偏好敏感；Market Regime必须作为最终闸门，而不是事后解释。

08｜Step 6：可能赚多少、亏多少？什么时候卖？

8.1 不给“目标价神谕”，只做条件敏感性

下面以2026H1每股归母净资产约 6.11元 为静态基准，对PB做敏感性演示。它的作用是帮助理解“市场溢价压缩/扩张会怎样影响价格”，不是预测未来目标价。

情景需要发生什么PB敏感性对应价格相对15.35元
压力情景 IPO进展停滞 / 主题退潮 / 估值溢价收缩 2.0× ¥12.23 -20.3%
当前附近 没有关键新增证据，维持现有资产包预期 2.5× ¥15.29 -0.4%
温和改善 多个IPO推进，但市场未进入事件亢奋 2.8× ¥17.12 +11.5%
强催化 蓝箭或核心项目出现实质状态跃迁，风险偏好配合 3.0× ¥18.34 +19.5%
事件亢奋 重新接近8月高预期状态，仅作敏感性参照 3.3× ¥20.18 +31.4%

PB仅是简化观察轴。创投公司的真实价值还要考虑投资组合公允价值、未上市资产、退出节奏、费用、税项、投资能力与市场风险偏好。

8.2 为什么“+20%～30%情景”不是预测？

CALCULATION若未来强催化使市场重新给予约3.0～3.3倍PB，静态对应约18.34～20.18元，即相对15.35元约+19%～+31%。这只是条件敏感性。

FACT3.3倍附近并非凭空选择：8月19日真实市场价格20.19元，大致对应当前静态H1每股净资产的3.3倍左右；随后市场迅速压缩该溢价。[S6]

CALCULATION若溢价压缩至2.0倍PB，静态价格约12.23元，相对15.35元约-20%。这说明事件股不是“下行很小、上行很大”的免费期权。

8.3 Exit State：卖点是状态迁移，不是一个神奇价格

S1 · THESIS BREAK
事件逻辑实质破坏

蓝箭审核实质恶化，或多个核心项目兑现能力一起变差。若买入逻辑是“资产包”而非单一蓝箭，一个项目失败不能自动等于全部Thesis死亡，需要重新计算组合。

S2 · EXPECTATION OVERDRAFT
股价跑得比事件/NAV快

例如蓝箭仍在C3，鲁信却重新进入强烈事件亢奋；如果市值增加远大于可解释的NAV变化，即使基本面没坏，赔率也可能已经恶化。

S3 · CATALYST REALIZATION
利好兑现后重新评估

上会、注册、发行、上市都不是“自动继续持有”的理由。每次状态跃迁都重新比较：这一步市场之前已经预期了多少？是否出现 Sell the News。

S4 · THESIS STAGNATION
没有坏消息，但一直不兑现

如果较长时间内关键IPO项目停留原状态、退出现金流没有增强，“时间没有发生事情”本身也会逐渐成为负面证据，因为事件驱动交易存在明确机会成本。

09｜这个Case让AlphaOS学到了什么？

9.1 不能把产业公司的CV体系硬套到创投平台

INFERENCE鲁信不是靠单一产品“试样→小批→量产→复购”兑现价值，更适合使用 Asset Realization / Catalyst State 表达：资产成熟 → IPO推进 → 上市 → 解禁 → 退出。

9.2 Event-Driven的基本结构

Event State ↓ Look-through / NAV Impact ↓ Expectation State ↓ Entry / Exit State 核心问题不是： “这是不是利好？” 而是： “事件确定性提高了多少？” “真实经济价值增加了多少？” “市场已经提前支付了多少？” “剩余赔率是否值得承担失败路径？”

9.3 买卖点更应该表达成“状态迁移”

INFERENCE本案例最重要的产品启发不是“蓝箭上会就买”，而是：

Entry Quality ≈ Event Progress 相对 Expectation Progress 的差。 这不是可直接套公式的数学模型，而是一种待继续验证的判断结构。

9.4 不急着新建一个庞大的 Event-Driven Engine

HYPOTHESIS为了控制AlphaOS v0.1范围，本案例更适合先沉淀为 Thesis Card + Event Monitor 内的一种 Event-Driven Template，而不是立刻膨胀出一个全新大引擎。

MISSING这一点仍属于案例发现，不自动升级为Core Spec正式规则；需要未来至少更多事件型案例交叉验证。
